Android 0.22.7/build247: 아이템 문구·피즈 상어 애니메이션·이미시브 위치/속도·금빛 발광을 수정했습니다. 존야는2초, 쿨감은 URF만 적용합니다. 같은 v0.22.7에 iOS0.22.7/build247 Xcode 준비물을 추가합니다. 내보내기는 성공했고 ZIP 검사·업로드 크기/digest 확인을 완료했습니다. 기존 iOS241과 이전 릴리스는 보존합니다. [Mac 설치·IPA 준비 안내](Docs/IOS_MAC_BUILD_GUIDE.md).

Xcode 준비물은 서명된 IPA가 아닙니다. Mac 실제 링크·서명·IPA 생성·실기기 설치는 미검증입니다.
