비공식 추억 체험용 앱의 배포 저장소입니다. 개발 소스는 별도 비공개 저장소에서 관리합니다.

Android/Xcode0.23.0/build250: 원래 시전 제한·탈론 궁 복원, 가렌 회전 이동/조건부 재사용, 체력바·공격 계수·경험치·솔로 치트를 조정했습니다. APK를 먼저 공개하고 Xcode250도 같은 릴리스에 동봉·검증했습니다. 기존249와 이전 릴리스는 보존합니다. [Mac 설치·IPA 준비 안내](Docs/IOS_MAC_BUILD_GUIDE.md).

Xcode 준비물은 서명된 IPA가 아닙니다. Mac 실제 링크·서명·IPA 생성·실기기 설치는 미검증입니다.
