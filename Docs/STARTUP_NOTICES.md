# 시작 공지 설정

이 문서는 APK 시작 화면의 공지 JSON을 수정하는 방법만 설명합니다. 서버 정책, 계정/DB, 앱 버전, 배포 범위를 변경하지 않습니다.

## 수정 위치

GitHub 저장소 `kimjae134679/PhoneLoL_02`의 `main` 브랜치에 있는 `Config/startup-notices.json`을 수정하고 저장합니다.

앱은 고정 HTTPS 주소에서 실행마다 한 번 읽습니다. **다음 실행부터 적용**되며 플레이 중 반복 조회하거나 팝업을 띄우지 않습니다. 이미 실행 중인 앱은 종료 후 다시 실행하세요. GitHub/CDN 반영 지연은 있을 수 있습니다.

새 설정을 읽는 데 최대 5초를 기다립니다. 네트워크 오류/잘못된 JSON은 마지막으로 검증된 설정을 유지하며, 캐시도 없으면 추가 공지 없이 기본 안내를 사용합니다. 정상적으로 받은 빈 `notices: []`는 추가 공지를 삭제합니다. 삭제 후 네트워크 오류가 나면 삭제된 최신 캐시가 유지됩니다.

## 연결 실패 뒤 로컬 플레이 (243부터)

처음에는 기존 온라인 연결을 시도하며 시작 모드 선택 화면을 추가하지 않습니다. 실제 연결 실패 뒤 혼자 플레이를 선택한 세션은 APK 내장 안내·기본 설정만 사용합니다. 이때 원격 캐시도 적용하지 않으며 공지·정책·업데이트·접속 현황 조회와 로그 업로드를 중단합니다. 기기 로그는 보존합니다. 온라인 접근 제한이나 필수 업데이트를 해제하는 기능은 아닙니다. 다음 실행은 다시 온라인 연결을 시도합니다.

## 이용 안내

APK에 들어 있는 첫 이용 안내는 신규 설치 및 새 앱 버전/빌드에서 표시됩니다. 팝업이 실제로 표시된 뒤 3초가 지나야 예/아니오가 활성화됩니다. 예만 동의를 저장합니다. 아니오와 활성화 후 Android 뒤로가기는 앱을 종료하며 동의를 저장하지 않습니다. 활성화 전 뒤로가기는 무시됩니다. 강제 종료/화면 닫힘도 동의가 아닙니다.

이 첫 이용 안내는 이 JSON으로 수정하거나 끌 수 없습니다. 문구는 안내일 뿐 권리자의 허락이나 법적 면책을 부여하지 않습니다. 문구에 언급된 서버 종료를 자동으로 수행하는 기능은 없습니다.

## 추가 공지 예시

아래 객체를 `notices` 배열에 추가합니다.

```json
{
  "id": "welcome-2026",
  "revision": 1,
  "enabled": true,
  "title": "추가 안내",
  "body": "안내 내용입니다.\n\n여러 줄도 사용할 수 있습니다.",
  "delaySeconds": 3,
  "buttons": "yesNo",
  "declineAction": "dismiss",
  "repeat": "oncePerRevision"
}
```

- `schema`: 1 고정.
- 문서 `enabled`: false면 추가 공지와 서버/업데이트 화면의 사용자 지정 표시를 사용하지 않습니다. **첫 이용 안내와 기존 서버 접근 제한/필수 업데이트는 유지됩니다.**
- `id`: 영문/숫자/`-`/`_`, 1~64자. 같은 배열에서 중복 불가.
- `revision`: 1 이상의 정수. 문구/설정 변경 시 증가시키면 같은 ID라도 다시 표시됩니다.
- 공지 `enabled`: false면 이 공지를 표시하지 않습니다.
- `title`: 최대 80자. `body`: 비어 있지 않은 최대 4,000자.
- `delaySeconds`: 0~30 정수. 실제 팝업 표시 시점부터 계산합니다.
- `buttons`: `confirm`(확인) 또는 `yesNo`(예/아니오).
- `declineAction`: `dismiss`(이번 실행에서 넘김) 또는 `quit`(앱 종료).
- `repeat`: `oncePerRevision`(해당 수정본을 예/확인한 뒤 생략) 또는 `always`(실행마다 표시).
- 아니오로 넘긴 추가 공지는 확인한 것으로 저장하지 않으므로 다음 실행에서 다시 나타날 수 있습니다.
- 확인 단추만 있는 공지에서는 숨겨진 아니오/뒤로가기 선택을 실행하지 않습니다.
- 전체 파일 UTF-8 32KiB 이하, 추가 공지 최대 10개. 범위를 벗어나면 파일 전체를 적용하지 않습니다.
- 텍스트의 `[FF0000]`, URL, HTML 등은 그대로 표시되는 일반 문자열입니다. 색상/링크/스크립트/NGUI 명령은 실행하지 않습니다. URL이나 실행 코드를 지정하는 설정은 지원하지 않습니다.

## 기존 서버 안내 / 업데이트 화면

`status`와 `update`는 동일한 `enabled`, `title`, `body`, `delaySeconds`, `buttons`, `declineAction` 설정을 사용합니다. `title`/`body`가 빈 문자열이면 앱/서버에서 정한 기본 내용을 유지합니다. `enabled: false`는 사용자 지정을 해제할 뿐 해당 화면이나 접근 제한을 비활성화하지 않습니다.

서버 안내는 기존 서버 정책에 표시할 내용이 있을 때만 나타납니다. 업데이트 안내는 기존 GitHub 릴리스 비교 또는 필수 업데이트 조건이 있을 때만 나타납니다. 이 파일은 공지의 표시만 수정하며 그 조건 자체를 만들거나 제거하지 않습니다.

필수 업데이트에서는 아니오로 넘겨도 로그인을 허용하지 않고 안내를 다시 표시합니다. 업데이트 링크는 항상 앱에 고정된 GitHub 최신 릴리스 주소입니다. JSON에 URL을 추가해도 사용하지 않습니다.

순서: 첫 이용 안내 → 추가 공지 → 기존 서버 안내 → 업데이트 → 로그인/이전 전투 재접속.
